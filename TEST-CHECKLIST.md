# Device test checklist

For each device open: Home, /manikyr/, /elektrolyse/, /vipper-bryn/, /blogg/, /kontakt/.

- [ ] Layout fits the screen, no sideways scrolling (portrait **and** landscape)
- [ ] Menu opens/closes (burger), links work, EN/NO switch works
- [ ] Hero panel: photo + text readable; buttons easy to tap
- [ ] Price cards: text readable on the photos, "Bestill" opens Timma
- [ ] Blog cards + reviews: equal heights, "Les mer" expands
- [ ] Contact form: validation messages, (optional) test send
- [ ] Cookie banner: appears once, buttons work, does not hide the content
- [ ] Bottom bar "Skriv / Bestill time" appears after scrolling on phones
- [ ] Fonts and images load (no empty boxes)

Suggested devices: iPhone (Safari), Android phone (Chrome), iPad (Safari),
desktop Chrome / Safari / Firefox / Edge, a small phone (320–360 px wide).
